# LaTeX draft (ICLR format)

Upload these to an Overleaf project created from the ICLR template — the
template supplies `iclr2026_conference.sty`, `iclr2026_conference.bst`,
`fancyhdr.sty` and `math_commands.tex`, which are not duplicated here.

    main.tex          the paper
    references.bib    25 entries, every arXiv id checked against arXiv
    numbers.tex       \newcommand per quoted quantity   } generated by
    tab_footprint.tex Table 1                           } experiments/
    tab_quality.tex   Table 2                           } build_paper_latex.py
    tab_ablation.tex  Table 3                           }
    figures/          PDF (vector, from the page's SVGs) and PNG figures

No number is typed into `main.tex`: the prose reads `\SaveRange`, the tables are
`\input`. After a rerun, regenerate them so the draft follows the data:

```bash
venv/bin/python -m experiments.build_paper_latex
```

`docs/index.html` is the same paper in full, with the appendices, the
interactive graphs and the four screenplays that do not fit a nine-page
submission.
